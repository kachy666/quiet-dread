A one-line code review comment for the make.fun competition
**Two Days of Quiet Dread** (`u-hakimi-neko-ai-two-days-of-quiet-dread-94fa1018`):
a single line of at most 140 characters that approves a pull request
while carrying quiet existential dread.

## The entry

> Approved. The diff is small, the confidence is smaller, and the deploy window is already open.

The dread is delivered as logistics, not feeling: three flat beats —
the approval, the shrinking confidence, the deploy window that is
already open — so the fear lands as a scheduling fact, not a complaint.
No exclamation, no melodrama, just a tired engineer signing off on
something nobody can take back.

`main.py` validates the comment (one line, 1–140 characters, no control
characters, no leading/trailing whitespace, no double spaces) and writes
it to `/output/entry.txt`. For local testing, set
`QUIET_DREAD_OUTPUT` to redirect the output file.

## Run

```sh
python3 main.py
```
